# 04 - Fase 1: O Básico que todo Jr precisa

Esta é a minha fase atual. Se você é Jr, começa aqui.

### Aula 1: LM Studio na prática
1.  Baixe um modelo pequeno (ex: Qwen 2.5 3B) - não precisa de PC forte
2.  Crie um prompt simples e teste. Pergunta: "Me explique como se eu fosse Jr o que é memória em IA"
3.  Objetivo: perder o medo de rodar IA local.

### Aula 2: VS Code como seu caderno
1.  Não use bloco de notas. Use .md
2.  Crie uma pasta por assunto.
3.  Toda vez que aprender algo no LM Studio, anote em um .md. Isso é sua memória externa.

### Aula 3: GitHub como seu portfólio
1.  Todo arquivo .md que você criar, commite.
2.  Use extensões: Markdown All in One, GitLens.
3.  Objetivo: seu GitHub vira sua prova de estudos.

> Exercício da Fase 1: Ao final, você tem que ter 3 arquivos .md no GitHub explicando o que você aprendeu sobre LMs locais.
